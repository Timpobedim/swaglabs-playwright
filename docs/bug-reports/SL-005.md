# SL-005. error_user: кнопка Finish не завершает заказ

| Поле | Значение |
|---|---|
| Серьёзность | Critical — покупку нельзя завершить |
| Приоритет | High |
| Окружение | https://www.saucedemo.com · Chromium 151 (Playwright 1.62, headless) · Windows 10 · 11.09.2026 |
| Пользователь | `error_user` |
| Воспроизводимость | стабильно |
| Автотест | `tests/guest/test_known_defects.py::test_error_user_can_finish_order` (xfail) |

## Шаги

1. Войти как `error_user` / `secret_sauce`.
2. Добавить в корзину «Sauce Labs Backpack», открыть корзину → **Checkout**.
3. Заполнить имя, фамилию и индекс → **Continue** → **Finish**.

## Ожидаемый результат

Страница **Checkout: Complete!** с текстом «Thank you for your order!».

## Фактический результат

После **Finish** остаётся открытым шаг **Checkout: Overview**, заказ не оформляется.

## Связанные наблюдения (без отдельных тестов)

- Поле **Last Name** не принимает ввод, но **Continue** пропускает дальше с пустой фамилией —
  валидация, которая работает у `standard_user`, здесь не срабатывает.
- При выборе сортировки появляется системный alert «Sorting is broken! This error has been
  reported to Backtrace.», порядок товаров не меняется.
- В корзину добавляются только два товара из шести, кнопка **Remove** не убирает товар.
