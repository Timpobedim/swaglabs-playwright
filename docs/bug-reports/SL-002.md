## Шаги

1. Войти как `problem_user` / `secret_sauce`.
2. Добавить в корзину «Sauce Labs Backpack», открыть корзину → **Checkout**.
3. Ввести в поле **First Name** «Анна», в **Last Name** — «Петрова», в **Zip/Postal Code** — «101000».
4. Нажать **Continue**.

## Ожидаемый результат

Поля содержат введённые значения, открывается шаг **Checkout: Overview**.

## Фактический результат

Текст, набранный в **Last Name**, попадает в **First Name** («Петрова»), поле **Last Name**
остаётся пустым. После **Continue** — ошибка `Error: Last Name is required`, дальше пройти нельзя.
