# SL-006. visual_user: цены в каталоге не совпадают с реальными

| Поле | Значение |
|---|---|
| Серьёзность | Major — покупатель видит одну цену, а платит другую |
| Приоритет | High |
| Окружение | https://www.saucedemo.com · Chromium 151 (Playwright 1.62, headless) · Windows 10 · 11.09.2026 |
| Пользователь | `visual_user` |
| Воспроизводимость | стабильно; сами значения меняются при каждой загрузке |
| Автотест | `tests/guest/test_known_defects.py::test_visual_user_sees_catalog_prices` (xfail) |

## Шаги

1. Войти как `visual_user` / `secret_sauce`.
2. Сравнить цены в каталоге с эталонными (`data/catalog.json`).

## Ожидаемый результат

$29.99, $9.99, $15.99, $49.99, $7.99, $15.99 — как у `standard_user`.

## Фактический результат

Случайные цены, при каждом входе разные (например, $91.75, $29.25, $68.07, $43.71, $55.55, $25.57).
При оформлении заказа сумма считается по настоящим ценам — на шаге Overview покупатель
видит итог, который не совпадает с ценами в каталоге.
