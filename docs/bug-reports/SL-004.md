# SL-004. problem_user: сортировка каталога не меняет порядок товаров

| Поле | Значение |
|---|---|
| Серьёзность | Major — функция не работает |
| Приоритет | Medium |
| Окружение | https://www.saucedemo.com · Chromium 151 (Playwright 1.62, headless) · Windows 10 · 11.09.2026 |
| Пользователь | `problem_user` |
| Воспроизводимость | стабильно |
| Автотест | `tests/guest/test_known_defects.py::test_problem_user_can_sort_by_price` (xfail) |

## Шаги

1. Войти как `problem_user` / `secret_sauce`.
2. В списке сортировки выбрать **Price (low to high)**.

## Ожидаемый результат

Цены по возрастанию: $7.99, $9.99, $15.99, $15.99, $29.99, $49.99.

## Фактический результат

Порядок не меняется: $29.99, $9.99, $15.99, $49.99, $7.99, $15.99. Так же ведёт себя
сортировка по названию Z→A. Ошибок на странице и в консоли нет — дефект «тихий».
